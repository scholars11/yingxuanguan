Windows 电脑版

安装版可自选目录、创建桌面与开始菜单快捷方式；绿色版解压即用，无需安装。均为 64 位，支持 Win10 及以上系统。
下载安装版Setup .exe 下载绿色免安装版Portable .exe

安装后怎么使用？

  • 打开影序馆后，右上角 ⚙ 可管理数据源（已内置多个默认源，直接可用）。
  • 在首页搜索框输入影视名称，或浏览分类，点击卡片即可查看详情并播放。
  • 软件内置本地代理服务，自动绕过跨域限制，无需额外配置服务器地址。

安装版和绿色版有什么区别？

  • 安装版（Setup）：向导式安装，可自选安装目录，自动创建桌面和开始菜单快捷方式，适合普通用户。
  • 绿色版（Portable）：单文件 exe，解压即可运行，不写入注册表，适合放在 U 盘随身携带。

下载被浏览器拦截怎么办？

由于安装包未经过数字签名，部分浏览器或安全软件可能会提示风险。 点击「保留」或「仍要运行」即可；如有疑虑，可查看 GitHub 仓库源码自行构建。

安全与免责

本软件不存储、不上传任何影视资源，所有数据均来自用户自行配置的公开数据源，请仅在拥有合法访问权限时使用。
